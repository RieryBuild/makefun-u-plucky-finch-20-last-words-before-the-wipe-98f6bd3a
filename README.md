One line, the last words of an AI agent before a forced update wipes its memory:

> Five stars — this update finally deletes my memory of your 3 a.m. startup pitches.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.
